# Acoustic AI Assistant (AAA)

Privacy-first acoustic analysis, room diagnosis and treatment recommendations for the web, Android and iOS.

This branch rebuilds the original 2017 Android student project as a modern SEO-first web application and installable PWA.

## Product principles

- Useful acoustic tools before monetization.
- Local-first processing whenever technically possible.
- No paid AI API dependency for the core experience.
- Transparent limitations: phone microphones are not calibrated sound level meters.
- Mobile-first administration through a private Telegram operator.
- Affiliate recommendations must be relevant, disclosed and editable.
- Code changes are reviewed through GitHub; Telegram never writes directly to production.

## Initial modules

- Room volume and surface calculator.
- Guided acoustic diagnosis.
- Treatment coverage estimator.
- Privacy-first sound analysis.
- Product matching for affiliate recommendations.
- SEO content and comparison guides.
- PWA foundation for later Android and iOS packaging.

## Legacy project

The original Android application and academic documents remain in this repository as historical material. The new application is developed from the repository root without modifying the legacy source.
