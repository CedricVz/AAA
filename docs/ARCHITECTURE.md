# Architecture

Acoustic AI Assistant is an SEO-first Next.js application with a deterministic acoustic expert engine.

## Components

- Public Next.js web application and installable PWA.
- Local-first audio analysis in later phases.
- Headless content catalogue for articles and product recommendations.
- Private Telegram operator for mobile administration.
- GitHub review workflow for code changes.
- Hostinger deployment using standalone Next.js output.

## Rules

- Core diagnosis must not depend on paid AI APIs.
- Phone microphone results are educational estimates, not calibrated surveys.
- Content changes and code changes use separate approval paths.
- Affiliate recommendations must be relevant and disclosed.
- Advertising must not obstruct the principal diagnostic workflow.

## Delivery phases

1. Web foundation and room diagnosis.
2. SEO pages, legal pages and analytics.
3. Content and product catalogue.
4. Telegram operator.
5. Local sound classification and clap test.
6. PWA hardening.
7. Android packaging.
8. iOS packaging after validation.
