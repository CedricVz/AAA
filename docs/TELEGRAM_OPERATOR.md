# Telegram Operator

Telegram is the private mobile control surface for Acoustic AI Assistant.

## Content operations

- Create and edit drafts.
- Upload media.
- Update recommendation records.
- Schedule approved content.
- Read product and traffic summaries.

## Approval workflow

Publishing, deletion, bulk edits and rule changes require a confirmation step.

Feature requests create a tracked GitHub task. Code changes are reviewed and tested before deployment; Telegram never writes directly to the production application.

## Access policy

Only the configured owner account can operate the bot. Every action is recorded and reversible where possible.
